# Структура git-репозитория

Следует использовать предложенную структуру git-репозитория. При необходимости создаются дополнительные папки верхнего уровня.

## Файловая структура git-репозитория

```text
/
├── README.md
├── docs/
│   ├── README.md
│   └── practice_documentation.md
│   └── ...
├── reports/
│   ├── README.md
│   └── report.pdf
│   └── ...
├── site/
│   ├── index.html
│   ├── css/
│   │   └── style.css
│   └── images/
│       └── logo.png
├── src/
│   └── main.py
│   └── ...
├── task/
│   ├── README.md
│   └── report_template.md
└── .gitignore
```

## Описание структуры git-репозитория

1. **Файл README.md**, расположенный в корневом репозитории, содержит основную информацию о проекте:
   * Описание практики.
   * Период проведения.
   * Участники (ФИО).
   * ФИО ответственного по проектной (учебной) иллюстрации.
   * Название проекта по «Проектной деятельности».
   * Куратор ФИО по проектной деятельности.
   * Формулировка задания вариативной части. Этот файл служит ориентиром для всех, кто работает с репозиторием.

2. **docs/** — Папка для размещения документации в формате Markdown:
   * **README.md** — основной файл с документацией, описывающий процесс выполнения практики.
   * При необходимости можно добавить дополнительные файлы Markdown.

3. **отчеты/** — Папка для хранения бинарных файлов отчётов:
   * **report.pdf** — пример итогового отчёта в формате PDF.
   * Возможны другие форматы (например, DOCX), если это необходимо.

4. **site/** — Папка для статического сайта со всеми его приложениями:
   * **index.html** — главная страница сайта.
   * **css/** — подпапка для стильных файлов:
     * **style.css** — пример файла стилей.
   * **images/** — подпапка для изображений:
     * **logo.png** — пример изображения (логотип или другая графика). Эта папка полностью изолирует ресурсы сайта от всей части проекта.

5. **src/** — Папка для исходного кода, созданная в рамках вариативного задания:
   * **main.py** — пример файла с кодом (например, на Python).
   * Структура внутри папок может изменяться в зависимости от потребностей проекта (дополнительные файлы или подпапки).

6. **задание/** — Папка для хранения текста задания и шаблона отчёта:
   * **README.md** — полный текст задания в формате Markdown.
   * **report_template.md** — шаблон отчёта, который участники могут использовать для подготовки итоговых документов.

7. **Файл .gitignore** — файл в корневом репозитории, предназначенный для исключения коммитов временных файлов, кэшей или других ненужных данных (например, `__pycache__`, `*.log`).

## Преимущества структуры

* **Чёткое отделение:** каждая папка отвечает за свою задачу, такую как быстрая навигация и управление проектом. Все элементы (README, задание, документация, отчеты, код, сайт) имеют свое место в репозитории.
* **Гибкость:** Структура позволяет легко добавлять новые файлы в соответствующие разделы (например, дополнительные отчеты или код).
